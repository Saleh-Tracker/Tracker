# ساعات العمل — Arbeitszeiten
تطبيق لتسجيل ساعات العمل اليومية وحساب الأجر (Kany Sicherung GmbH)

## الملفات
- `Code.gs` — الخلفية داخل Google Sheet (Apps Script)
- `index.html` و `manifest.json` و `sw.js` و `icon-192.png` و `icon-512.png` — التطبيق؛ ارفع الخمسة معاً في نفس المستودع على GitHub Pages

## خطوات التشغيل
1. أنشئ ملف Google Sheet جديداً باسم مثلاً **Arbeitszeiten**.
2. من القائمة: **Extensions > Apps Script**، احذف المحتوى والصق `Code.gs`.
3. غيّر السطر `const API_KEY = 'CHANGE-ME-1234';` إلى كلمة سر خاصة.
4. اختر الدالة **setup** واضغط **Run** مرة واحدة ووافق على الصلاحيات. ستُنشأ الأوراق: Entries, Settings, Holidays, Adjustments, Payslips.
5. **Deploy > New deployment > Web app**:
   - Execute as: **Me**
   - Who has access: **Anyone**
   ثم انسخ رابط الـ Web App.
6. ارفع الملفات الخمسة على GitHub Pages (Settings > Pages > main / root).
7. في التطبيق: **الإعدادات > الاتصال**: الصق الرابط وكلمة السر، ثم "اتصال ومزامنة".

> بدون رابط يعمل التطبيق محلياً على الهاتف، وعند الاتصال لاحقاً يعرض رفع الإدخالات المحلية إلى الشيت.
> عند أي تعديل على `Code.gs`: **Deploy > Manage deployments > Edit > New version** ليبقى الرابط نفسه.

## الشاشات
- **اليوم:** إدخال اليوم مع حساب فوري (الإجمالي، المعفى، الصافي). بعد الحفظ يجهّز اليوم التالي بنفس المكان والوظيفة.
- **الشهر:** قائمة الأيام، الإجمالي أسفل الصفحة، تنبيه لأيام العمل بلا إدخال، تعديلات ومكافآت، وطباعة بنفس شكل نموذج Stundennachweis.
- **المقارنة:** إدخال أرقام كشف الراتب وعرض الفرق بنداً بنداً.
- **الإعدادات:** الأجور، النسب، العطل الرسمية، الاتصال، وزر عربي/ألماني في الأعلى.

## العطل الرسمية
مُعبّأة مسبقاً لعامي 2026 و2027 (العطل العامة + Fronleichnam لولاية هيسن). العطلة تُحتسب حسب مكان العمل، فأضف عطل الولاية التي يعمل فيها من الإعدادات.

## التثبيت كتطبيق
- **أندرويد / ويندوز (Chrome أو Edge):** افتح الرابط، يظهر زر **تثبيت** أعلى الصفحة.
- **آيفون (Safari فقط):** زر المشاركة ⬆️ ثم **إضافة إلى الشاشة الرئيسية** (تظهر رسالة توضيحية داخل التطبيق).
- التطبيق يفتح بدون إنترنت ويعرض آخر نسخة، والتحديثات تظهر تلقائياً عند الاتصال.

## العمل بدون إنترنت
أي إدخال أو تعديل بدون إنترنت يُحفظ على الهاتف، ويظهر عدّاد أصفر تحت العنوان: "3 إدخالات بانتظار الإرسال".
عند عودة الإنترنت تُرسل تلقائياً بنفس الترتيب (أو اضغط على العدّاد للإرسال فوراً).
